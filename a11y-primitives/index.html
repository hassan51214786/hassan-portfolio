Keyboard Navigable Tabs

A fully accessible tab component. Use Tab to focus the tablist, then use Arrow Right and Arrow Left to navigate between tabs. Focus is managed manually via JavaScript to conform to WAI-ARIA authoring practices.

Focus-Trapped Modal

A modal dialog that correctly manages focus state. When opened, focus is moved to the first focusable element inside. While open, focus is trapped within the modal so keyboard users cannot interact with the background. Escape closes it and returns focus to the trigger button.
